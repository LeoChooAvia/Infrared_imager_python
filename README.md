# Infrared Imager Python Tool — Инструмент для обработки инфракрасных изображений

Программа предназначена для анализа данных ИК-тепловизоров, преобразования сохраненных CSV в визуальные карты температур (false color) или тепловые диаграммы. Работает с файлами сырых снимков этого тепловизора -> https://youtu.be/7j6DSND6Ass

## 🚀 Инструкция по установке и запуску (для Windows пользователей)

Программа гарантированно работает на Python версии **3.13**. Версия python должна иметь поддержку Tkinter(tk), поэтому python 3.15 не подойдёт. Для корректной работы необходимо выполнить следующие шаги в терминале:

### Шаг 1: Установка Conda
Если у вас еще нет пакетного менеджера, установите [Miniconda](https://docs.anaconda.com/miniconda/) или Anaconda (рекомендуется Miniconda для легкости). После установки перезапустите командную строку Windows (`cmd` или `PowerShell`).

### Шаг 2: Создание окружения
Выполните команду создания изолированной среды с нужной версией Python:

```bash
conda create -n thermal python=3.13
```

Активируйте созданное окружение командой (вы должны выполнять её каждый раз, когда открываете новый терминал):

```bash
conda activate thermal
```

### Шаг 3: Установка зависимостей
Убедитесь, что вы находитесь в корневой папке проекта и активированное окружение `thermal` показывает актуальную версию Python. Затем установите все необходимые библиотеки одной командой:

```bash
pip install -r requirements.txt
```

### ✅ Запуск программы
Теперь программу можно запускать из этого же терминала (при всегда активном окружении):

```bash
python src/main.py
