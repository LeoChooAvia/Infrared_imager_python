# GUI: Termal Imadger 1.0

Описание графического интерфейса приложения для визуализации тепловизионных данных
(матрица температур 24×32, считанная из CSV-файла). Приложение построено на Tkinter.

![Главное окно с загруженным изображением](<GUI/Вставка 17.11.2026 в 10:09:53.png>)

## Общая компоновка окна

Окно 840×440, размер фиксированный (не масштабируется), заголовок — `Termal Imadger 1.0`.
Состоит из двух зон:

| Зона | Что находится |
|------|---------------|
| Левая панель (~250 px) | Все органы управления: поля температур, выпадающие списки, чекбокс, поле результата, кнопка «Применить» |
| Правая область | Полотно (canvas) 577×433 с тонкой рамкой цвета `#80CBC4`, на которое выводится тепловое изображение |

В начальном состоянии (изображение ещё не загружено) правая область — пустая белая,
поля температур пусты, поле температуры точки показывает `None`, кнопка «Применить»
неактивна (серая).

![Начальное состояние без изображения](<GUI/Вставка 17.11.2026 в 10:11:39.png>)

## Меню macOS

Поскольку Tkinter на macOS выносит главное меню в системный верхний бар, у приложения
есть два пункту меню:

- **Файл**
  - **Открыть** — открывает системное диалоговое окно выбора файла (обычный macOS
    file dialog). Выбирается CSV-файл с матрицей температур 24×32. Пока файл читается,
    пункт «Открыть» блокируется (закрашивается), чтобы избежать повторного запуска.
    После загрузки изображение сразу выводится на экран, а поля «Минимальная/
    Максимальная температура» автоматически заполняются фактическими значениями из файла.
  - разделитель
  - **Выйти** — завершает приложение.
- **Справка**
  - **Я ничего здесь не придумал** — единственный (заглушечный) пункт меню.

## Левая панель управления

Сверху вниз:

1. **Минимальная температура:** + текстовое поле.
   Только для чтения, пока файл не загружен. После загрузки заполняется минимальным
   значением из CSV. Можно редактировать вручную: новое значение используется как
   нижняя граница шкалы при перерисовке (пережатие палитры).

2. **Максимальная температура:** + текстовое поле.
   Аналогично — после загрузки заполняется максимумом из CSV, редактируется пользователем
   и задаёт верхнюю границу шкалы.

3. **Алгоритм интерполяции:** + выпадающий список (combobox).
   Определяет, как изображение 24×32 масштабируется до 576×432 (методы resize PIL).
   Список содержит 9 вариантов:
   `BOX` (по умолчанию), `LINEAR`, `BILINEAR`, `CUBIC`, `BICUBIC`,
   `LANCZOS`, `ANTIALIAS`, `NEAREST`, `HAMMING`.
   Для большинства «честных» методов (LANCZOS, BICUBIC и т.п.) изображение выглядит
   сглаженно; `BOX`/`NEAREST` дают «пиксельный» вид.

   ![Список алгоритмов интерполяции](<GUI/Вставка 17.11.2026 в 10:11:58.png>)

4. **Цветовая палитра:** + выпадающий список, 2 варианта:
   - `Iron` (по умолчанию) — «железная» (ironbow) палитра из 433 цветов:
     тёмно-синий → фиолетовый → красный → белый по мере роста температуры;
   - `black and white` — ч/Б (серая) шкала: чёрный — холод, белый — жар.

   Цвет каждого пикселя выбирается по нормированной температуре в пределах
   [мин, макс], заданных полями 1–2.

   ![Список палитр](<GUI/Вставка 17.11.2026 в 10:11:48.png>)

5. **Чекбокс «Маркеры максимальной и минимальной температуры»** (включён по умолчанию).
   При включении поверх изображения рисуются маркеры 9×9:
   - **красный** — на ячейке с максимальной температурой;
   - **синий** — на ячейке с минимальной температурой.

   Маркеры видны на первом скриншоте этого документа.

6. **Подпись «Температура в указанной точке: (клик правой кнопкой мыши и применить)
   (*работает только в методе BOX)».**
   Инструкции по точечному измерению температуры.

7. **Поле отображения температуры в точке** (только чтение, по центру, крупным шрифтом).
   До первого замера показывает `None`. Работает так: правый клик по изображению
   запоминает позицию пикселя → нажимается «Применить» → приложение по цвету этого
   пикселя в палитре Iron восстанавливает температуру и выводит её сюда.
   Связано с тем, что обратное соответствие «цвет → температура» однозначно
   реализуется только для BOX-масштабирования.

8. **Кнопка «Применить»** (внизу, на всю ширину панели).
   Изначально неактивна; активируется после первой загрузки файла.
   При нажатии перерисовывает изображение по текущим настройкам:
   - читает значения из полей «Минимальная/Максимальная температура»
     (пустое поле трактуется как «автоматически, по факту из файла»);
   - пересчитывает цвета по выбранной палитре;
   - масштабирует изображение выбранным алгоритмом интерполяции;
   - сохраняет результат в `new.png` и выводит на правую область;
   - обновляет маркеры (если чекбокс включён);
   - обновляет поле температуры в точке (для BOX; иначе `None`).

## Область изображения (правая)

- Белое полотно с рамкой; до загрузки файла пусто.
- Загруженное изображение растягивается на всю область (576×432).
- **Правый клик мыши** по изображению задаёт точку измерения (см. п. 7 левой панели);
  позиция запоминается и учитывается при следующем «Применить».
- **Маркеры** (красный/синий, 9×9) отмечают пиксели максимума/минимума, если чекбокс включён.
- Каждое нажатие «Применить» добавляет новый слой изображения поверх прежнего
  (старый слой не удаляется, новый перекрывает его).

## Типовой сценарий работы

1. Запустить приложение (окно пустое, «Применить» неактивна).
2. **Файл → Открыть** → выбрать CSV (24 строки × 32 столбца температур, °C).
   Изображение появляется, поля температур заполняются (например, 1.04 / 35).
3. При необходимости:
   - поправить min/max в полях и нажать «Применить» (пережатие шкалы);
   - сменить палитру или алгоритм интерполяции и нажать «Применить»;
   - отключить маркеры и нажать «Применить»;
   - кликнуть правой кнопкой по нужной точке и нажать «Применить» (BOX) —
     в поле под инструкцией появится температура этой точки.
4. Выход: **Файл → Выйти** или закрыть окно, подтвердив диалогом.
